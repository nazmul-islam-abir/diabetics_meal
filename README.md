# আমার ডায়েট — Flutter + Supabase

ডায়াবেটিস-বান্ধব বাংলাদেশি খাবার পরিকল্পনা অ্যাপ। সার্ভার-সাইড Supabase ব্যবহার করে
ক্লিনিক্যাল ক্লাসিফিকেশন (HbA1c, BMI, BP, CKD, হৃদরোগ) এবং ৩০ দিনের ঘূর্ণায়মান খাবার তালিকা
সরবরাহ করে। ইউজার প্রতিটি খাবার টিক দিয়ে খাওয়া/বিকল্প/পরিকল্পনার বাইরে লগ করতে পারে এবং
তাৎক্ষণিকভাবে জানতে পারে বিকল্পটি তার জন্য ভালো নাকি খারাপ।

## সেটআপ

1. **Supabase প্রজেক্ট তৈরি করুন** — supabase.com এ নতুন প্রজেক্ট বানান।
2. **SQL রান করুন** — SQL Editor-এ `supabasesql/` ফোল্ডারের ফাইলগুলো **এই ক্রমে** রান করুন:
   - `01_schema.sql` — টেবিল, RLS পলিসি
   - `02_rpcs.sql` — `classify_user()`, `get_daily_recommendation()`, `record_meal_intake()` ইত্যাদি
   - `03_seed_foods.sql` — মাস্টার খাবার তালিকা
   - `04_seed_alternatives.sql` — প্রাথমিক বিকল্প
   - `05_meal_intake_actions.sql` — লগ + রেসিপি + হাইড ফিচার
   - `06_seed_mealplan.sql` — ৩০ দিনের ঘূর্ণায়মান পরিকল্পনা
   - `07_more_alternatives.sql` — বাংলাদেশি সাশ্রয়ী বিকল্প (ওটস → রুটি, ইলিশ/কাতলা →
     রুই/শিং, আমদানি ফল → পেয়ারা/পেঁপে)
   - `08_signup_identity.sql` — সাইনআপে নাম + মোবাইল সংগ্রহ
3. **Auth চালু করুন** — Supabase Dashboard → Authentication → Providers-এ Email/Password
   চালু আছে কিনা নিশ্চিত করুন।
4. **`.env` বসান** — `.env.example` কপি করে `.env` বানান এবং নিজের কী বসান:
   ```
   SUPABASE_URL=https://your-project.supabase.co
   SUPABASE_ANON_KEY=your-anon-key
   ```
   (Project Settings → API থেকে পাবেন)
5. **প্যাকেজ ইনস্টল করুন**:
   ```
   flutter pub get
   ```
6. **রান করুন**:
   ```
   flutter run
   ```

## অ্যাপের ফ্লো

1. **`AuthScreen`** — সাইনআপে নাম + মোবাইল + ইমেইল + পাসওয়ার্ড নেয়; লগইনে শুধু ইমেইল +
   পাসওয়ার্ড। Supabase Auth user_metadata-এ `full_name` ও `mobile` সংরক্ষিত হয়; `08_signup_identity.sql`
   এর ট্রিগার সেগুলো `public.user_profiles`-এ মিরর করে।
2. **`OnboardingScreen`** — ক্লিনিক্যাল তথ্য (নাম, মোবাইল, বয়স, ওজন, উচ্চতা, গ্লুকোজ, HbA1c,
   ওষুধ, BP, কিডনি/হৃদরোগ/রক্তস্বল্পতা, জীবনযাত্রা) নিয়ে `public.user_profiles`-এ সেভ হয়।
   প্রোফাইল এডিট করতেও এই স্ক্রিন ব্যবহার হয়।
3. **`HomeShell`** — বটম নেভিগেশন: `আজ` (টুডো লিস্ট) / `ড্যাশবোর্ড` / `প্রোফাইল`।
4. **`MealPlanScreen`** (আজ) — প্রতিটি পরিকল্পিত খাবার একটি কার্ড; টোকা দিলে একশন শীট আসে:
   - **হ্যাঁ, এটাই খেয়েছি** — লগ ভালো হিসেবে
   - **বিকল্প খাবার খেয়েছি** — সার্ভার থেকে ৪টি বিকল্প আনে, প্রতিটির পাশে থাম্বস-আপ / ডাউন /
     প্রশ্ন চিহ্ন এবং কারণ (CKD, BP, GI)
   - **পরিকল্পনার বাইরে অন্য কিছু খেয়েছি** — ফ্রি-টেক্সট দিয়ে লগ
5. **`DashboardScreen`** — স্ট্রিক, ভালো/মাঝারি/খারাপ অনুপাত বার, সাপ্তাহিক বার চার্ট, ম্যাক্রো
   গড়, আজকের লগ।
6. **`ProfileScreen`** — অ্যাকাউন্ট কার্ড (নাম মোবাইল ইমেইল), শারীরিক তথ্য, বর্তমান ক্লাসিফিকেশন
   স্তর, বিশেষ শারীরিক অবস্থা, আপডেট বাটন (অনবোর্ডিং স্ক্রিনে ফেরত যায়), লগআউট।

## ইমপ্যাক্ট ক্লাসিফায়ার

`lib/services/impact_engine.dart` হলো SQL-এর `classify_user()` ফাংশনের একটি ক্লায়েন্ট-সাইড
মিরর। এটি তাৎক্ষণিকভাবে (অফলাইনে) বিকল্প খাবারের গুণগত মান (ভালো / মাঝারি / খারাপ) এবং কারণ
বাংলায় দেখায়। আসল সিদ্ধান্ত সবসময় সার্ভার-সাইড `record_meal_intake()` থেকে আসে; দুটো একসাথে
আপডেট রাখুন যদি লজিক পরিবর্তন করেন।
- এই অ্যাপের ডেটাসেট এবং ক্লাসিফিকেশন থ্রেশহোল্ড সাধারণ ক্লিনিক্যাল নীতিমালার (ADA/WHO/ACC-AHA
  স্টাইল কাটঅফ) ওপর ভিত্তি করে তৈরি অনুমান — প্রোডাকশনে যাওয়ার আগে একজন ডায়েটিশিয়ান/চিকিৎসক
  দিয়ে যাচাই করিয়ে নিন, বিশেষত CKD-সম্পর্কিত খাদ্য বাদ দেওয়ার লজিক।
- ফন্ট: `NotoSansBengali` রেফারেন্স করা আছে `main.dart`-এ কিন্তু অ্যাসেট যোগ করা হয়নি — হয়
  Google Fonts থেকে .ttf যোগ করুন `pubspec.yaml`-এ, অথবা `fontFamily` লাইনটি বাদ দিন সিস্টেম
  ডিফল্ট ফন্ট ব্যবহার করতে।
- অ্যাপ প্রবীণ-বান্ধব: ১৭-১৯ পয়েন্ট বডি টেক্সট, ৫৬-পিক্সেল বোতাম, বাংলা লেবেল।
